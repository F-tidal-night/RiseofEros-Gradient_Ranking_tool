使用教程

欢迎使用欲神幻想梯度榜

FTN工作室出品。数据都存你浏览器里，随便加卡不卡不崩；换设备之前记得先“导出数据”。

主要更新

  • 评级换成 T 级：PVE/PVP 用 T0~T3（T0最高、T3最低）。旧版 10 分数据第一次打开会自动换算：10→T0、9-8→T0.5、7-6→T1、5-4→T2、3及以下→T3，不用手动改。
  • 资料库一键更新：点“导入/更新资料库”就能拿到新评级、新角色。星级是你的练度，永远不动；评级和评价想保留自己那版，就勾“保留”。
  • v3.3 角色类型：新增防御型、攻击型、回复型、辅助型。可以按类型筛选，也能在批量修改里统一设置；旧角色不设置类型也照常使用。

主要功能（一句话看懂）

  • 加角色：起个名、填星级和评级，就是一张卡；还能加图、写两句备注
  • 配队模拟：把角色拖进队伍，或者直接点卡片上的“加入队伍”；想换位置，拖一下就互换
  • 角色类型：可选防御型、攻击型、回复型、辅助型；卡片和配队里会显示对应小图标，旧角色不设置也能正常用
  • 搜索排序：想找谁就搜名字，想排强度就按星级/PVE/PVP评级排，也能单独筛角色类型
  • 批量改：一堆角色一次性改星级、评级或角色类型，不用一张一张点
  • 回收站：手滑删了？去回收站捞回来就行
  • 更新资料库：点“导入/更新资料库”就能拿到最新评级和评价，你的练度不会丢
  • 图片自动配：图包文件名规规矩矩的话，选好图点一下“自动匹配”就全对上了

怎么用（超简单版）

1. 加角色

  • 名字：照“角色名-皮肤名”填，比如 露妃-墨染金香，以后自动配图才找得到
  • 星级：按你账号里实际练度填
  • 评级：T0 最高，T3 最低，工作室每版会更新
  • 角色类型：防御型 / 攻击型 / 回复型 / 辅助型，选填；不选就不显示类型图标
  • 评价：想写就写，不写也不拦你
  • 图片：传不传都行，不传先用默认图顶着，之后随时能补

2. 配队

  • 顶部队伍1~4，点哪个就配哪个队
  • 放人：拖过去，或点卡片下面绿色的“加入队伍”；队伍满4人后按钮会变灰，想换人就把新卡拖到已有角色身上顶掉
  • 调位置：队伍里直接把卡拖到另一个格子，会互换/挪位
  • 不要了：点格子里的 ×，或拖回“我的角色”区域

3. 管理卡片

  • 卡片右上角三个小图标：改 / 删 / 藏
  • 删除先进回收站，还能捞回来；彻底清掉才真正没
  • 藏起来的角色在页面下方“被隐藏的角色”里，也能搜索
  • 点“角色评价”看备注，点一下收起

4. 备份 / 换设备

  • 导出数据 = 把整份存档下成一个 json 文件
  • 导入数据 = 把存档恢复回来；导入前会自动帮你备份当前数据，不怕手滑
  • 数据存在浏览器里，换电脑、清缓存、换浏览器之前，先导出一份，不然找不回来

5. 官方资料库更新

  • 工作室出新评级/新角色时，点“导入/更新资料库”
  • 网页版直接点“从服务器获取最新官方包”；群文件版就选命名是“欲神幻想梯度榜官方资料库vX.X.X.json”的文件
  • 星级、隐藏状态、队伍配置永远不动；评级和评价想保留就勾上对应的“保留”
  • 角色类型会跟随官方包更新；官方包没带类型时保留你原来的设置
  • 更新完如果新角色没图，把图包里的图放进 images 文件夹，或直接批量导入一次

6. 批量加图

  • 图包文件名是“角色名.png/webp”就能自动认：选图 → 点“按文件名自动匹配” → 应用更改
  • 个别名字对不上，就手动一张张点着配，不麻烦

7. 常见问题

  • 图片传不上去？看看是不是格式/损坏问题，jpg、png、webp 都支持
  • 批量导入报错/卡？别一次全选，按角色分批来
  • 数据没了？十有八九是换浏览器/清缓存了，养成“动浏览器前先导出”的习惯

注意事项

  • 推荐使用 Chrome、Edge 等稳定浏览器
  • 请勿随意修改官方图包，以防数据损坏
